# Local MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a fully local MVP pipeline that runs data generation, conversion, research target generation, risk adjustment, paper execution, and report generation end to end.

**Architecture:** Keep the MVP deterministic and file-based. Use Pydantic schemas for contracts, write every run output under `artifacts/`, maintain a lightweight `latest.json` run index, and expose the workflow through `quant-agent`, Makefile targets, and script wrappers.

**Tech Stack:** Python 3.10+, Typer, Pydantic, PyYAML, pandas, pytest, ruff, mypy.
