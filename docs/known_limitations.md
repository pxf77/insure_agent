# 已知限制

- AkShare 适配器当前不能提供严格流程所需的完整复权、历史 CSI300 成分、
  停复牌和涨跌停数据，因此会 fail closed。
- Tushare 适配器按历史 CSI300 成分逐证券拉取，首次长窗口同步较慢且受积分、
  权限和频率限制影响；尚未实现断点分页和跨日增量缓存。
- Qlib 二进制布局和真实工作流已接入，但完整 Alpha158 集成测试只有安装
  `research` extra 且具有足够历史快照时才执行。默认 CI 只验证可读取布局和
  “缺依赖不回退”。
- 当前研究输出包含整体样本外指标；分年度、滚动窗口、系统化参数扰动和自动
  泄漏扫描仍应在策略晋级工具中继续扩充。
- 默认研究配置声明周频再平衡，但 CLI 不替代交易日调度策略；外部调度器仍需
  决定哪些交易日进入人工审批。数据健康与组合监控可以每日运行。
- 日线 paper 只模拟完整成交或当日未成交，不模拟盘口、排队、部分成交或
  盘中撤单。
- SQLite 仅面向单用户、本地单机串行运行；没有多机写入协调。
- `latest.json` 表示最近完整运行，不代表任何真实券商账户状态。
- MLflow、vn.py、RD-Agent/LLM、只读券商、`live_shadow`、`live_manual`、
  常驻服务和无人值守实盘未实现。
